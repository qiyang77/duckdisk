# Security Policy

## Supported Versions

DuckDisk is currently in early development. Please use the latest release for security fixes.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security issue in DuckDisk, please do not open a public issue.

Report it privately by emailing:

```text
qiyang577@gmail.com
```

Please include:

- A clear description of the issue
- Steps to reproduce
- The affected DuckDisk version
- Your macOS version
- Any relevant logs, screenshots, or proof of concept details

I will try to respond as soon as possible. If the report is valid, I will work on a fix and coordinate disclosure before publishing details publicly.
