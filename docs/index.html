Cloud storage analysis

Your cloud storage, without the download.

Connect OneDrive or Google Drive and DuckDisk scans storage metadata through the provider API. Large cloud libraries can be analyzed without making every file available offline.

  • Metadata-only full scans with resumable checkpoints
  • Delta updates from the last completed cloud scan
  • Fast follow-up scans from provider change records
  • Move selected items to the provider's recoverable trash

Questions

Before you scan.

Why does DuckDisk ask for Full Disk Access?

macOS protects folders such as Photos, Mail, Downloads, and application data independently. Full Disk Access reduces permission gaps during a whole-disk scan.

Why can scanned file space differ from macOS storage usage?

macOS includes APFS system volumes, snapshots, VM storage, filesystem metadata, and other reserved space. DuckDisk's tree represents files and folders it can enumerate.

Does cloud scanning download my files?

No. DuckDisk reads file and folder metadata from Microsoft Graph or Google Drive API. File contents are not downloaded for analysis.

What happens when I delete a cloud item?

DuckDisk asks the provider to move the selected item to OneDrive's Recycle Bin or Google Drive Trash, where it can normally be restored.
