## What's New in 0.6.4

- Local scans disable automatic cloud materialization before scanning, including path metadata and cached-scan checks. Skipped cloud-only files and folders are marked explicitly, with unknown contents shown as a dash instead of an empty folder.
- Cloud-only files appear as one grouped Scan Issue, while file and folder totals include descendants omitted from the displayed tree depth. OneDrive's known cloud-only sync mirror no longer inflates the local logical size.
- Fixed ordinary sparse files being mistaken for cloud placeholders: logical size remains accurate even when allocated space is zero.
- Added cloud connection and request timeouts. Cancelling OneDrive or Google Drive scans now drops pending network waits, token refreshes, and retry backoff. Trash moves have a longer timeout and are not blindly retried if the result is uncertain.
- Corrected apparent and allocated totals to preserve hard-link deduplication in the result view, incremental caches, and folder refreshes.
- Added disk capacity, macOS used space, color-coded Free space, and an **Unscanned** column for whole-volume scans. Click the question mark to understand usage outside the scan and review unreadable paths.
- Fixed missing permission-error reports. Scan issues remain available when results are reopened from cache; cloud skips are counted separately from read failures.
- Added **Copy Current Path** to the toolbar and removed the redundant Selected column.
- Disk usage refreshes after local deletions. Older scan caches are rebuilt once for corrected accounting and cloud-placeholder handling.

### Downloads

- **Apple Silicon:** `DuckDisk_0.6.4_arm64.dmg`
- **Intel:** `DuckDisk_0.6.4_x86_64.dmg`

Both editions are signed with a Developer ID certificate and notarized by Apple. Automatic updates are supported on both architectures.

Installation: Download the .dmg for your Mac, open it, and drag DuckDisk into Applications.

This is a replacement build of 0.6.4. If you installed 0.6.4 before this September 30, 2026 replacement, download and reinstall it to receive these additional fixes; same-version replacements do not trigger automatic updates.

For more complete local scans, enable Full Disk Access for the installed DuckDisk app, restart it, and run a full rescan. Some system permissions and APFS-managed usage cannot be represented as ordinary scanned files. Unscanned is the difference between live macOS used space and the entire scan's deduplicated allocated total, not a list of files to delete. Cloud-only remote content is not local used disk space.
